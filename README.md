# C# / Windows Forms — Visual Studio

Practical programming activities in C# using Windows Forms and Visual Studio.

## Folders

| Folder | Contents |
|---|---|
| [`review-activities/`](review-activities/) | Complete solution with 8 review forms covering programming logic exercises, including conversions and a calculator, with actual dates for each form |
| [`activity-06-09/`](activity-06-09/) | Complete project for a loop exercise using `while`, `do-while`, and `for` |
| [`practical-exam-2b2/`](practical-exam-2b2/) | Complete practical exam project, including the compiled executable |
| [`individual-exercises/`](individual-exercises/) | 9 individual exercises from separate Windows Forms projects |
| [`exercise-documents/`](exercise-documents/) | Exercise statements and answers covering loop structures |

## Dates

This repository contains some of the strongest date evidence among the projects collected so far.

- The `practical-exam-2b2/` folder comes from the original Visual Studio project `.zip`, including the hidden `.vs/` folder and the compiled executable. The internal timestamps of the project files date to **August 17, 2022**.
- The `review-activities/` folder includes a screenshot of the Solution Explorer with the system clock visible (**April 30, 2022**) and a screen recording of Visual Studio with an internal creation date of **February 28, 2022**.
- The `activity-06-09/` project contains internal file timestamps from **September 6, 2022**, including `Program.cs` and the final `Form1.cs`.

The student ID `12100161`, which appears in multiple materials, including the Mesadinha, Computing Environments, and Database projects, also provides consistent context for the 2021–2022 timeline.
