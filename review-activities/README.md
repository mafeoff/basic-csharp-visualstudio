# Review Activities — C# / Windows Forms

Complete Visual Studio solution with a separate form for each programming logic review exercise, using Windows Forms and C#. It now includes the `.Designer.cs` files and the compiled executable, extracted directly from the original project `.zip`.

## Forms

| File | Description |
|---|---|
| `FrmLetraA.cs` | Converts age in years to months by multiplying by 12 |
| `FrmLetraB.cs` | Calculates the price of a product after applying a percentage discount |
| `FrmLetraC.cs` | Calculates the square root of a number |
| `FrmLetraD.cs` | Change calculator (amount paid − product price) |
| `FrmLetraE.cs` | Calculates the amount to pay based on weight, multiplying it by a fixed rate |
| `FrmLetraF.cs` | Calculates the cube of a number |
| `FrmLetraG.cs` | Calculates the sum, average, and (incomplete) percentage of three numbers — this file contains an unfinished line (`float Resultado2 =`), so it does not compile as it is |
| `FrmCalculadora.cs` | Simple calculator with addition, subtraction, multiplication, and division |
