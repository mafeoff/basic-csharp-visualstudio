# Como publicar este repositório no GitHub (usando GitHub Desktop)

1. Abra o GitHub Desktop e faça login com sua conta.
2. **File → New Repository**, nome `csharp-visual-studio`.
3. Copie o conteúdo desta pasta (README.md e as 4 subpastas) para dentro da pasta local criada.
4. Escreva uma mensagem de commit, ex.: `Atividades de C# / Windows Forms`.
5. **Commit to main** → **Publish repository**.

> Dica: o arquivo `.exe` compilado em `prova-2b2-12100161/compilado-evidencia/` é um binário — o GitHub aceita normalmente, só não é possível visualizá-lo online (é só para download).
