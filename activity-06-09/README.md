# Activity 06/09 — Loops

Complete Visual Studio project for a loop exercise using `while`, `do-while`, and `for`, including the `.sln`, `.csproj`, and `.Designer.cs` files.

## What the Application Does

Three buttons solve the same problem of counting from one number to another using three different loop structures:

- `while`
- `do-while`
- `for`

The application also includes a button to clear the input fields.
